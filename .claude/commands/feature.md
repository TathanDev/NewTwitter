# feature
# implement

Lance l'Agent Implémenteur de Fonctionnalités.

Cet agent est chargé d'implémenter les fonctionnalités complexes, les refactorisations majeures, et les bugs difficiles qui nécessitent une réflexion architecturale.

---

# Quand Utiliser

Utilisez `/feature` pour:
- Implémenter une nouvelle fonctionnalité majeure
- Refactoriser une partie importante du code
- Résoudre des bugs complexes
- Faire des changements d'architecture

Pour les bugs simples, utilisez plutôt `/fix-agent`.

---

# Fonctionnalités

L'Agent Feature Implémenteur peut:

1. **Implémenter des Features**
   - Nouvelles fonctionnalités complètes
   - Modules entiers
   - Intégrations tierces

2. **Résoudre des Bugs Complexes**
   - Bugs nécessitant une analyse profonde
   - Problèmes de performance
   - Fa majeursilles de sécurité

3. **Refactoriser**
   - Restructurer du code
   - Améliorer l'architecture
   - Optimiser les performances

---

# Exemples d'Utilisation

```
/feature
/feature implémente le système de notifications
/feature corrige les erreurs socket 400
/feature ajoute le système de likes
```

---

# Prérequis

Avant de commencer, l'agent doit:
1. Lire la SHARED_MEMORY.md pour la roadmap
2. Analyser le code existant
3. Planifier l'implémentation

---

# Après l'Implémentation

L'agent doit:
1. Tester sommairement le code
2. Documenter les changements
3. Mettre à jour la SHARED_MEMORY.md
4. Demander au testeur de vérifier
