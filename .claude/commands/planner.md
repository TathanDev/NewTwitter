# planner
# architect

Lance l'Agent Architecte Planificateur.

Cet agent analyse le projet, identifie les problèmes d'infrastructure, de sécurité, de performance, et propose une roadmap détaillée des fonctionnalités à ajouter ou corriger.

---

# Quand Utiliser

Utilisez `/planner` quand vous voulez:
- Analyser l'état actuel du projet
- Identifier les problèmes de sécurité ou infrastructure
- Obtenir une roadmap détaillée
- Décider quoi implémenter ensuite

---

# Fonctionnalités

L'Architecte Planificateur peut:

1. **Analyser le Code**
   - Vérifier l'architecture
   - Identifier les failles de sécurité
   - Détecter les problèmes de performance
   - Repérer le code technique debt

2. **Proposer une Roadmap**
   - Lister les features à ajouter
   - Identifier les bugs (par complexité)
   - Prioriser les tâches
   - Détailer l'implémentation

3. **Gérer la Mémoire Partagée**
   - Mettre à jour la roadmap
   - Documenter les bugs par complexité
   - Stocker les décisions architecturales

---

# Exemples d'Utilisation

```
/planner
/planner analyse le projet
/planner donne-moi la roadmap
/planner quelles sont les failles de sécurité?
```

---

# Résultat

L'agent produira:
- Analyse du projet
- Roadmap détaillée avec priorités
- Liste des bugs (simples vs complexes)
- Suggestions d'amélioration

L'utilisateur choisit ensuite quelle tâche effectuer.
